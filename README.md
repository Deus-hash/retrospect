# Retrospect — Интерактивная открытая энциклопедия ретро-гейминга и платформа легальной эмуляции

> Проект разработан для межвузовского конкурса **«Студенческий IT-стартап»**  
> **Организатор:** ФГБОУ ВО «Брянский государственный инженерно-технологический университет» (БГИТУ) при поддержке Брянской городской администрации.

---

## 🌟 1. О проекте

**Retrospect** — это легальная цифровая веб-экосистема для сохранения, изучения и воспроизведения ретро-видеоигр. Проект решает фундаментальную проблему отрасли: **переход от нелегальных пиратских сервисов к прозрачной, юридически чистой и коммерчески эффективной платформе**.

Платформа сочетает:
1. **Открытую энциклопедию (Knowledge Base):** 9 культовых консолей (8, 16, 32, 64-bit), 479 игр, характеристики, история, аксессуары.
2. **Браузерную среду эмуляции WebAssembly (Zero-Install):** мгновенный запуск в браузере без скачивания эмуляторов, BIOS и плагинов.
3. **Каталог 100% легальных Homebrew & Open-Source игр:** официальные релизы от инди-авторов со свободными лицензиями (MIT, GPL, CC, zlib, Freeware).
4. **Готовую открытую библиотеку игр:** отсутствие необходимости самостоятельного поиска или установки игр — 97 легальных игр запускаются мгновенно прямо в браузере.
5. **B2B-модель «RetroKiosk SaaS»:** готовое решение для легального развлечения гостей в кафе, антикафе, отелях и культурных центрах г. Брянска и регионов РФ.

## ⚖️ 2. Юридическая чистота и авторские права

В соответствии с требованиями законодательства РФ (Часть IV Гражданского кодекса РФ) и критериями конкурса (п. 5.2 и 5.3 Положения):

* **Статья 1274 ГК РФ:** Все информационные и исторические статьи, скриншоты и обзоры видеоигр используются исключительно в информационных, исследовательских и культурных целях с обязательным указанием правообладателей.
* **Отсутствие пиратских дампов:** На серверах проекта не хранятся проприетарные коммерческие ROM-файлы (Nintendo, Sega, Konami, Capcom и т.д.).
* **Легальность эмуляции (ст. 1280 ГК РФ):** Эмуляторы воссоздают архитектуру микропроцессоров методом обратной разработки без использования чужого закрытого кода (прецеденты *Sony v. Connectix*, *Sony v. Bleem*).
* **97 встроенных легальных игр:** Общественное достояние (Public Domain), свободные релизы авторов, Open Source и Homebrew (Twintris, Bike Race 98, Takatron 2084, Halo 2600, Cheril the Goddess, Sir Ababol, Bomb X, Bare Knuckle Princess, BLT, Furry RPG, 3D City, Anguna, Alter Ego, 2048, Old Towers, Super Tilt Bro, Cave Story MD и др.). Открытая библиотека для NES, Sega Mega Drive, SNES, Sega Master System, Atari 2600, Nintendo 64, PlayStation и PC Engine.

Подробный реестр лицензий и правовой меморандум доступны в приложении на странице [`/legal`](http://localhost:3000/legal).

## 💼 4. Бизнес-модель и монетизация стартапа

1. **B2B SaaS («RetroKiosk»):**  
   Готовый веб-терминал с PIN-защитой, турнирной таблицей и легальными играми для заведений сферы HoReCa (антикафе, бары, лаунжи, отели) от **2 490 ₽/месяц**.
2. **B2B2C Маркетплейс («Homebrew Launchpad»):**  
   Дистрибуция новых игр от инди-разработчиков для ретро-платформ, предзаказы физических картриджей и мерча (комиссия **15%**).
3. **B2C Подписка («Retrospect Pass»):**  
   Кроссплатформенные облачные сохранения (Cloud Saves), мультиплеер через WebRTC, кинематографичные CRT-шейдеры (**199 ₽/месяц**).

* **TAM:** $4.5 млрд (Мировой рынок ретро-игр и инди-ретро)
* **SAM:** 450 млн руб. (Рынок тематических заведений и развлечений РФ)
* **SOM (2 года):** 18.5 млн руб. годовой выручки (50 000 MAU + 120 B2B-заведений).

## 🚀 5. Установка и запуск

### Системные требования:
* **Node.js:** v18.0.0 или новее
* **MongoDB:** v5.0+ (локальная или облачная Atlas)
* **Браузер:** Любой современный с поддержкой HTML5 Canvas и WebAssembly

### Шаги запуска:
```bash
# 1. Перейдите в папку проекта
cd c:\Users\Deus\Desktop\Retrospect

# 2. Установите зависимости (если еще не установлены)
npm install

# 3. Наполните базу данных легальными играми и консолями
npm run seed

# 4. Запустите автотесты (проверка 18 маршрутов)
npm test

# 5. Запустите сервер проекта
npm start
```

После запуска перейдите в браузере по адресу:  
👉 **http://localhost:3000**

## 🏆 7. Соответствие критериям конкурса «Студенческий IT-стартап»

* **Актуальность и инновационность (5/5):** Трансформация пиратского рынка ретро-игр в легальную цифровую экосистему и инструмент цифровизации сферы HoReCa (B2B SaaS).
* **Концепция (5/5):** Четкое разделение базы знаний (ст. 1274 ГК РФ), WebAssembly песочницы и коммерческих B2B/B2C модулей.
* **Реализация MVP (30/30):** Полностью рабочий кроссплатформенный продукт с 9 консолями, 29 играбельными легальными играми, поддержкой Drag & Drop ROM, сохранениями, сенсорным управлением и REST API.
* **План выхода на рынок (5/5):** Оценка TAM/SAM/SOM, конкурентный анализ, каналы привлечения клиентов и расчет юнит-экономики.
